# 03 Explanation

03 是反解：用传感器九个读数算出整个旋钮的 6DOF 位姿变量（3位移，3角度）。

---

大概做法是：先随便给一个位姿，可以直接用上一帧的结果。把它代进 02，算出九个“应该的值”。将九个“应该值”跟实测的九个读数逐个相减，得到残差。依据残差反推六个未知数各自该挪动多少。这其实和机械臂的 FK、IK 大差不差。

挪动之后，再算，重复直到残差不再下降（收敛）。

## Levenberg-Marquardt 非线性最小二乘算法

以下给出我尽力而为的理解。

```
Δ = (JᵀJ + λI)⁻¹ [Jᵀ(b_measurement − f(p))]
p ← p + Δ

`Δ` 6*1 列向量：x,y,z,rx,ry,rz。指这一步要挪多少增量
`J` 9*6 Jacobian，每个读数对六个未知量各求一次偏导。用于局部线性近似
`λ` 阻尼系数。λ=0 是硬牛顿，在行程两头发散；升高它加大分母，减小步长，迭代次数加大
`I` 6×6 单位阵
`b_measurement` 9×1 列向量：三颗传感器实测的九个读数（U1xyz、U2xyz、U3xyz）。这是已知量，读回来的。
`f(p)` 9×1 列向量：把 p 代进 02 正解式子算出来的九个读数。

`Jᵀ`和逆：代数计算，没有什么含义。Jᵀ为了凑方阵，逆为了矩阵除法。
```

拿不耦合的单变量举例，现在知道实测值b mT，也知道当前假设值a mT，也知道变化规律（线性系数j mT/mm）。要求动多少位置(Δx)能动到b mT。也就是：
```
j * Δx = b - a
Δx = (b - a) / j
```
实际情况是变量间的线性近似会耦合，所以使用矩阵一次性计算。这样耦合项也算进去了。

---

使用 L-M 方法让误差收敛到真实值附近即可。

**1. 算差 (b_measurement − f(p))**：假设这一刻的位姿就是上一刻的位姿`p`（*也许可以依据运动趋势（dx/dt & dv/dt）猜一下*）。拿这一刻假设位姿用一次正解，算出九个预测 B 解`f(p)`。

和实测读数`b_measurement`相减，得到九个 B 读数误差`b_measurement − f(p)`（残差）。

**2. 得到雅可比矩阵 `J` (also `Jᵀ`)**：通过假设单变量的微小位姿变化（一共假设 6 次，因为 6DOF），用6次正解得到对应的六组 9 个 B(x)，B(y)，B(z) 的变化量（就是`位姿变化后的 B 解` - `第一步的预测 B 解`）。和单位量相比得到偏导，填入9*6雅可比矩阵。（在这里定义足够小的单位位移是 1um（0.001mm），单位旋转是 0.0001rad）

为什么每次计算都要重新算 J 呢？因为磁铁运动引起的 B 变化是非线性的。J 只是局部线性近似。

这里JᵀJ矩阵的问题是，x，y，z的敏感度远小于rx，ry，rz的敏感度。角度稍微动一下，Δ中rx，ry，rz就会走的过大。所以rx，ry，rz项需要乘以更大的 `λ` 阻尼。


**3. 解Δ**：用 JᵀJ 的 6*6 方程组，一次把这六个量全部解出来。得到这次应该动的位置(Δ)

至于`λ`是干什么的，它在这里用于控制收敛速度，以及防止发散。想象求逆相当于置于分母，防止解趋于无穷造成发散。

## 为什么是 3 个传感器

九条方程六个未知量，有唯一最小二乘解。平移时三颗有共模变化，倾斜旋转时有差模变化。

为什么不是两个呢？设想一个磁铁绕着两个传感器的轴旋转的情况，两颗读数差不多同步变化。而且也没有多余的验算检查。
